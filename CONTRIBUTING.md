# Contributing

Keep contributions generic and safe for a public repository.

- Use fictional or bracketed placeholders instead of real names, addresses, phone numbers, emails, domains, store identifiers, or customer content.
- Do not include screenshots containing personal accounts, browser tabs, local paths, tokens, or private infrastructure details.
- Run the secret scanner and validation commands from the README before opening a pull request.
- Preserve Persian RTL behavior, keyboard accessibility, reduced-motion support, and WordPress escaping/sanitization conventions.

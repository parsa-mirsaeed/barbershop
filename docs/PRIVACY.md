# Privacy design

WooCommerce should remain the system of record for products, customers, addresses, orders, refunds, and fulfilment. The companion plugin stores only public portfolio content, two attachment IDs, a service label, and a publication-consent confirmation flag.

Cardholder data must be entered on a hosted payment-provider page and must not be collected or logged by this project.

A checked consent box is an editorial safeguard, not the consent record itself. Keep the actual permission record in controlled business records and apply an appropriate retention policy.

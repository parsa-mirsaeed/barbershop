# راهنمای پیامک، ورود با موبایل و افزونه‌های تجارت ایران

این راهنما انتخاب‌های مناسب برای فروشگاه فعلی را از هم جدا می‌کند تا «اعلان ضروری سفارش»، «ورود با رمز یک‌بارمصرف»، «ارسال ایران» و «درگاه پرداخت» به یک افزونه پیچیده و وابسته تبدیل نشوند.

## پیشنهاد نهایی برای این پروژه

### ۱. اعلان سفارش به آرایشگر: افزونه پیامک ووکامرس فارسی

برای اطلاع فوری آرایشگر بعد از خرید، پیشنهاد پایه پروژه افزونه رایگان **Persian WooCommerce SMS** است:

- اعلان سفارش جدید یا تغییر وضعیت سفارش برای مدیر، مشتری و مدیر محصول؛
- پشتیبانی از سرویس‌های رایج ایرانی مانند کاوه‌نگار، ملی‌پیامک، SMS.ir و IPPanel؛
- امکان استفاده از الگوی خدماتی/پترن برای تحویل مطمئن‌تر پیام‌های تراکنشی؛
- امکان اعلان رایگان از طریق ربات بله یا تلگرام در نسخه‌های جدید، در کنار پیامک پولی.

نکته مهم: خود افزونه رایگان است، اما ارسال SMS معمولاً رایگان نیست. پنل پیامک، خط خدماتی یا الگو و اعتبار ارسال را باید از ارائه‌دهنده تهیه کنید.

نصب پیشنهادی:

```bash
make iran-commerce
```

سپس در پیشخوان وردپرس:

1. تنظیمات پیامک ووکامرس فارسی را باز کنید.
2. پنل پیامک خود را انتخاب و کلید/API را وارد کنید.
3. اعلان مدیر برای «سفارش جدید» یا وضعیت «در حال انجام» را فعال کنید.
4. شماره موبایل آرایشگر را به‌عنوان گیرنده مدیر ثبت کنید.
5. متن کوتاه شامل شماره سفارش، مبلغ، نام مشتری و لینک مدیریت سفارش بسازید.
6. یک سفارش آزمایشی ثبت و ارسال واقعی را بررسی کنید.

نمونه متن مدیر:

```text
سفارش جدید #{order_id}
مشتری: {billing_first_name}
مبلغ: {order_total}
وضعیت: {order_status}
```

نام متغیرها بسته به افزونه و سرویس پیامک متفاوت است؛ از فهرست متغیرهای همان صفحه تنظیمات استفاده کنید.

## ۲. ورود مشتری: موبایل یا ایمیل + رمز عبور

هسته فروشگاه اکنون بدون افزونه اضافه از این روش پشتیبانی می‌کند:

- کاربر با **شماره موبایل یا ایمیل** و رمز عبور وارد می‌شود؛
- نام کاربر شناسه ورود نیست؛
- شماره موبایل هنگام ثبت‌نام الزامی، نرمال‌سازی‌شده و یکتا است؛
- ورود با رمز عبور حتی در صورت اختلال پنل پیامک کار می‌کند.

این روش برای نسخه اولیه ساده‌تر، ارزان‌تر و پایدارتر از OTP است.

## ۳. ورود اختیاری با رمز یک‌بارمصرف

OTP را فقط زمانی فعال کنید که واقعاً برای نرخ تبدیل یا پشتیبانی لازم باشد. گزینه‌های شناخته‌شده شامل **WP SMS / WSMS** و افزونه‌های اختصاصی «OTP Login & Register for WooCommerce» هستند. قبل از انتخاب، باید در محیط آزمایشی بررسی شود که افزونه موردنظر:

- سرویس پیامک ایرانی شما را مستقیماً پشتیبانی کند یا API سفارشی داشته باشد؛
- با ووکامرس، HPOS، قالب بلوکی و زبان فارسی سازگار باشد؛
- ورود با رمز عبور را به‌عنوان مسیر جایگزین حفظ کند؛
- شماره‌های `+98`، `0098`، `98` و `09` را به یک قالب یکتا تبدیل کند؛
- حساب تکراری برای یک شماره نسازد.

### الزامات امنیتی OTP

- عمر کد: حدود ۲ تا ۵ دقیقه؛
- فاصله ارسال مجدد: حداقل ۶۰ ثانیه؛
- محدودیت تلاش برای هر شماره، IP و نشست؛
- پیام خطای یکسان برای شماره موجود و ناموجود تا وجود حساب افشا نشود؛
- ذخیره کد به‌صورت هش‌شده و موقت؛
- حذف کد پس از مصرف موفق؛
- عدم ثبت کد خام در لاگ؛
- استفاده اجباری از HTTPS؛
- ثبت رویدادهای مشکوک و امکان مسدودسازی موقت؛
- مسیر بازیابی امن در صورت قطع سرویس پیامک.

به همین دلیل اسکریپت پروژه OTP را خودکار نصب یا فعال نمی‌کند.

## ۴. ارسال داخل ایران

افزونه رایگان **Persian WooCommerce Shipping** از مجموعه نابیک برای شروع مناسب است و اسکریپت `make iran-commerce` آن را نصب می‌کند. امکانات متداول آن شامل روش‌های پست، تیپاکس، پیک/باربری، شهرهای ایران، اتصال‌های مرتبط با تاپین و سازگاری با HPOS است.

پس از نصب:

1. به ووکامرس ← پیکربندی ← حمل‌ونقل بروید.
2. یک منطقه برای ایران بسازید.
3. فقط روش‌هایی را که واقعاً استفاده می‌کنید اضافه کنید.
4. مبدأ، وزن محصولات، محدودیت شهر، هزینه پایه و قواعد ارسال رایگان را تنظیم کنید.
5. برای تهران یا شهر محل فروشگاه، پیک محلی را جدا از ارسال کشوری تعریف کنید.
6. با چند وزن، شهر و مبلغ سبد خرید تست کنید.

نسخه Pro نابیک زمانی ارزش دارد که نرخ‌های جدید، شرط‌های پیچیده، چند شرکت حمل، محاسبات پیشرفته یا اتوماسیون بیشتر لازم باشد. ابتدا نسخه رایگان را با فرآیند واقعی فروشگاه آزمایش کنید.

## ۵. پرداخت

پروژه در نصب اصلی این دو گزینه را فراهم می‌کند:

- **ZarinPal for WooCommerce** برای اتصال مستقیم زرین‌پال؛
- **Gateland** از نابیک برای مدیریت و انتخاب میان چند درگاه و سناریوهای هوشمندتر.

برای فروشگاه کوچک، یک درگاه فعال و یک مسیر پشتیبان کافی است. فعال‌کردن تعداد زیادی درگاه بدون نیاز واقعی، تنظیمات و پشتیبانی را پیچیده می‌کند.

## ارتباط نابیک با پیامک

نابیک در مستندات افزونه‌های خود برای اعلان‌های پیامکی به **Persian WooCommerce SMS** متصل می‌شود؛ برای نمونه، افزونه «ندا» و ارسال پیشرفته نابیک با این افزونه پیامک یکپارچه می‌شوند. بنابراین برای این پروژه، نابیک انتخاب اصلی بخش ارسال و درگاه است و افزونه پیامک ووکامرس فارسی انتخاب اصلی اعلان سفارش.

## حریم خصوصی و رضایت کاربر

هنگام استفاده از سرویس پیامک یا شرکت حمل، صفحه حریم خصوصی باید نام یا دسته ارائه‌دهنده، نوع داده ارسالی و هدف ارسال را توضیح دهد. پیام ضروری سفارش را از پیام تبلیغاتی جدا نگه دارید. شماره موبایل ثبت‌شده برای رسید، امنیت و وضعیت سفارش نباید بدون رضایت جداگانه وارد فهرست تبلیغاتی شود.

صفحه‌های «سیاست حریم خصوصی» و «شرایط استفاده و خرید» توسط Barbershop Core ساخته و به وردپرس/ووکامرس متصل می‌شوند، اما متن آن‌ها الگوی اولیه است. مدیر فروشگاه باید نام حقوقی، نشانی، روش‌های ارسال، ارائه‌دهندگان واقعی، شرایط مرجوعی و الزامات کسب‌وکار خود را بازبینی کند.

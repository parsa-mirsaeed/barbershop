# نصب مرحله‌به‌مرحله

## نصب خودکار با Docker

```bash
./tools/install.sh
```

در اولین اجرا، `.env` و رمزهای تصادفی ساخته می‌شود؛ وردپرس، ووکامرس، Wordfence، قالب و Barbershop Core فعال می‌شوند؛ دسته‌بندی‌ها و ثبت‌نام کوتاه تنظیم می‌شود و وزیرمتن به‌صورت محلی دریافت می‌شود.

سایت پیش‌فرض روی `http://127.0.0.1:8080` است. اگر این درگاه اشغال باشد، نصب‌کننده نخستین درگاه آزاد بعدی را انتخاب، `WP_PORT` را در `.env` ذخیره و نشانی نهایی را چاپ می‌کند. این رفتار فقط برای توسعه محلی است؛ production به درگاه‌های ۸۰ و ۴۴۳ نیاز دارد.

بعد از نصب:

1. رمز مدیر را از `.env` بردارید و فایل را خصوصی نگه دارید.
2. **Wordfence** را باز کنید، ایمیل هشدار و فایروال را تکمیل و احراز هویت دومرحله‌ای مدیر را فعال کنید.
3. **مدیریت فروشگاه** را باز و لوگو، محصولات، دسته‌ها و ایمیل سفارش را تکمیل کنید.

## نصب روی هاست وردپرسی

```bash
./tools/build-release.sh
```

1. `dist/persian-barbershop-theme.zip` را در پوسته‌ها نصب کنید.
2. `dist/barbershop-core-plugin.zip` را در افزونه‌ها نصب کنید.
3. WooCommerce و Wordfence را از مخزن رسمی وردپرس نصب و فعال کنید.
4. قالب و Barbershop Core را فعال کنید.
5. **مدیریت فروشگاه** را باز و «اجرای ترمیم امن» را بزنید تا دسته‌ها، تنظیمات و فونت آماده شود.
6. Wordfence، HTTPS، پشتیبان، ایمیل تراکنشی و درگاه را جداگانه پیکربندی و آزمایش کنید.

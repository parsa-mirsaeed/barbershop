Persian WooCommerce UX, minimal customer accounts, editable category icons, store dashboard, local Vazirmatn provisioning, security hardening, and consent-aware portfolio controls.

== Description ==

Barbershop Core adds:

* first name, last name, email, and optional phone registration without profile address fields;
* persistent desktop cart and mobile store dock;
* editable product category icons and seeded Persian product taxonomy;
* Persian labels and redesigned WooCommerce customer flows;
* a product publication checklist and Persian store-control dashboard;
* conservative headers, user-enumeration restrictions, no-cache commerce pages, and optional XML-RPC disabling;
* local Vazirmatn font installation;
* documented-consent checks for before/after portfolio entries.

The installer installs Wordfence separately from the official WordPress repository. No security plugin or custom code can guarantee absolute security; operators must complete firewall, 2FA, update, backup, monitoring, and hosting controls.

== Installation ==

1. Install and activate WooCommerce.
2. Install and activate Wordfence, then complete its firewall and administrator 2FA setup.
3. Activate Barbershop Core.
4. Open **مدیریت فروشگاه** and run the safe repair/setup action.
5. Review privacy, payment, email, backup, and production security settings.
